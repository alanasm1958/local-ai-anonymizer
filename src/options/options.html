Set up a local model

  1. Install Ollama (or LM Studio).
  2. Download a small model: ollama pull llama3.2
  3. Keep Ollama running, then press Test detection above.

If the test says HTTP 403, quit Ollama and start it with OLLAMA_ORIGINS="chrome-extension://*" ollama serve.
